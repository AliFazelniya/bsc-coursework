# Scientific Computing Project 1

This project is a numerical methods assignment focused on root-finding and approximation techniques. It implements several classic methods for solving equations numerically, including bisection, Newton-Raphson, secant, and simple iteration.

## Project Overview

The purpose of this project is to compare and apply numerical methods for finding roots of equations. These methods are fundamental in scientific computing because many real-world problems cannot be solved analytically.

## Implemented Methods

- Bisection method
- Newton-Raphson method
- Secant method
- Simple iteration method
- Aitken acceleration (where included)

## Project Structure

- analysis/: contains analysis scripts and comparison logic
- method/: contains the implementation of each numerical method

## Requirements to Run

This project is written in Python. Run the desired script directly using:

```bash
python <filename>.py
```

For example:

```bash
python method/bisection.py
```

## Notes

This project demonstrates how numerical algorithms can be implemented step by step and compared for accuracy and convergence behavior.
