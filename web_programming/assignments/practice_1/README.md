# Web Programming Practice 1

This practice exercise is a simple static web page implementation using HTML and CSS. It demonstrates the basic structure of a web document and the styling techniques used to create a visually organized interface.

## Project Overview

The goal of this assignment is to practice building a webpage with semantic HTML and visual styling using CSS. It focuses on the foundation of front-end development: content structure, layout, and presentation.

## What the Project Contains

- index.html: the page structure and content
- style.css: styling rules for layout, colors, spacing, and typography

## Requirements to Run

Open the HTML file in a web browser:

```bash
xdg-open index.html
```

## Notes

This is a beginner-friendly exercise that introduces the core concepts of static web page development.
