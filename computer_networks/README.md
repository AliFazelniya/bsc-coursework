# Computer Networks

This folder contains the academic work completed for Computer Networks during the B.Sc. program in Computer Science at Shahid Madani University.

## Course Information
- Institution: Shahid Madani University
- Degree: B.Sc. in Computer Science
- Instructor: Dr. Mohsen Haydarian
- Focus Area: Network architectures, protocols, routing, and communication systems.

## Contents and Purpose
This directory is intended to preserve and organize the main learning artifacts for this subject, including:
- Lecture notes and study references
- Assignments and problem-solving exercises
- Project work and practical implementation files
- Exams, presentations, or supplementary materials where available

## How to Use This Folder
1. Review the notes first to build conceptual understanding.
2. Study the assignments to practice the techniques covered in class.
3. Examine the projects and exams for applied problem-solving experience.
4. Use this folder as a structured academic archive for revision and reference.
