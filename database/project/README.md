# Database Project

This project is a database-driven application designed to manage and analyze football-related data. It combines Python scripts, SQL queries, and a graphical user interface to provide useful insights about players, coaches, and team statistics.

## Project Overview

The system is built around a structured dataset and several Python modules that interact with SQL queries to answer meaningful questions. The project demonstrates how database concepts can be applied to real-world data and displayed in an organized, user-friendly way.

## Main Features

- Import and process football dataset information
- Query player and coach data using SQL
- Generate insights such as best attackers and best assists
- Present results through a GUI application
- Use custom styling and structured interface components

## Project Files

- Main.py: main application entry point
- Players.py: player-related logic and data handling
- Coachs.py / Head Coachs.py: coach-related representations and processing
- Best Attackers.py: logic for identifying top attackers
- Best Assists.py: logic for identifying top assist providers
- dataset.py: dataset preparation and loading
- comments.sql: SQL comments or notes used during development
- SQLQuery1.sql / SQLQuery3.sql: example SQL queries
- Script.py: supporting script logic
- theme.qss: stylesheet for the GUI

## Requirements to Run

This project uses Python and SQL-based data handling. The environment should have:

- Python 3
- PyQt5 (if the GUI is used)
- A compatible SQL environment if the database queries are executed directly

Run the main application with:

```bash
python Main.py
```

## Notes

This project is a strong example of applying database design, SQL queries, and user interface programming together in one academic project.
